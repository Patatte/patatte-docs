# Gather event operations

## Before the event

1. Confirm the event name, dates and service windows.
2. Add the participating vendors and correct menus.
3. Confirm whether attendees or the organiser pay.
4. Test each published link or QR code.
5. Confirm fulfilment ownership and the support contact for the event.

## During the event

- Monitor ordering availability and vendor queues.
- Keep menu changes controlled and visible.
- Record payment or fulfilment incidents once, using the order reference.
- Do not create a replacement event link during live service without notifying vendors and organisers.

## After the event

Export the final order and payment information, record refunds and unresolved exceptions, and retain the event reference used for reconciliation.
