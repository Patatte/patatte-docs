# GO storefront, kiosk and POS

## Storefront

Customers open the vendor link, select from the live menu, configure an item, choose fulfilment, pay using an enabled method and retain the order reference.

## Self-service kiosk

1. Start a fresh order before entering customer information.
2. Confirm that the kiosk shows the expected site and menu.
3. Select items and required options.
4. Review the cart and fulfilment choice.
5. Complete the enabled payment flow.
6. Record the order number before leaving the kiosk.

If another guest's cart is visible, cancel it safely or ask a supervisor for help. Do not continue it.

## Staff POS

1. Sign in with the assigned staff account or approved POS access method.
2. Confirm the active site and register.
3. Start the shift where required.
4. Build and review the order with the customer.
5. Select the payment channel actually received.
6. Submit once and confirm the order reference.
7. End or hand over the shift using the approved procedure.

Cashiers should capture orders and payments. Refund approval, reconciliation, account settings and broad reporting should remain with authorised administrators.
