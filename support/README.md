# Troubleshooting

Use this section before escalating an ordering or fulfilment issue.

## First response

1. Stop repeated order submissions or payments.
2. Record the product, venue and ordering channel.
3. Capture the order, transaction, programme or event reference.
4. Record the exact time, time zone and visible status.
5. Check connectivity and refresh once.
6. Follow the relevant guide.
7. If unresolved, use the [support escalation checklist](escalation.md).

## Safety rules

- Do not submit an order again until the first attempt has been checked.
- Do not repeat a payment because confirmation is delayed.
- Never share passwords, full payment credentials or unredacted personal data.
